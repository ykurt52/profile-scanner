Method

  • Only public, non-fork repos owned by the user are scanned; data comes from the official GitHub REST API.
  • Languages come from GitHub byte counts; purpose from manifest files, file layout, languages and keywords; sector from words in descriptions, topics and READMEs.
  • Repos pushed in the last 12 months count fully, 1-3 years at 0.6, older ones at 0.3.
  • Private and organization repos are not included, so results may not reflect the person's full skill set.
